래치 L1 : 전기가 나갔다가 들어오면 내부릴레이는 날아가는데 래치는 이전 걸 기억함
	평소에는 내부릴레이와 같음.

SFL, SFR(P) : 좌, 우 쉬프트 로테이션 X
EX) [SFLP K4Y30 K1]

ROL, ROR(P) : 좌, 우 쉬프트 로테이션 O
EX) [ROLP K4Y30 K1]

WOR : 워드 OR
EX) [WOR D1 K4X10 K4Y30]

WAND : 워드 AND
EX) [WAND HFFFF K4X10 K4Y30]

MC, MCR : 기준으로 회로를 끊을수있음.
EX) |M0|---[MC N0 M10]
     ~
     --------[MCR N0]

MC 실행 지령이 OFF 일 때 MC에서 MCR 명령 사이 연산결과
 고속타이머, 저속타이머 : 현재값 0, 코일, 접점은 OFF된다
 
 카운터, 적산타이머 : 코일은 OFF되지만 카운터 현재값, 접점은 모두 현재 상태유지
 
 OUT 명령 디바이스 : 모두 OFF된다

 SET, RST, SFT 명령 기본, 응용 : 현재상태 유지

CJ, SCJ
CJ: 실행 조건이 ON되면 현재 스캔에서 즉시 P1으로 점프한다.
CJ 명령 다음부터 P1 직전까지의 프로그램은 실행하지 않는다.

SCJ: 실행 조건이 ON된 현재 스캔에서는 점프하지 않고, 다음 스캔부터 P1으로 점프한다.
SCJ 명령 다음부터 P1 직전까지의 프로그램은 실행하지 않는다.

FEND 뒤에는 보통 서브루틴이나 인터럽트 프로그램을 작성
...한다.

CALL, RET

CALL: 실행 조건이 ON이면 지정한 포인터 P1의 서브루틴으로 이동하여 실행한다.

RET: 서브루틴 실행을 끝내고, CALL 명령 다음 위치로 돌아간다.

CALL은 RET과 항상 함께 사용해야함
FEND이후는 CALL을 ON해야 사용가능
