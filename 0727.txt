# GLOFA 입력 주소 정리

```text
%IX 베이스.슬롯.비트번호
%IB 베이스.슬롯.바이트번호
%IW 베이스.슬롯.워드번호
```

* `IX` : 1비트 단위

  * `X0` → 0번 비트
  * `X1` → 1번 비트

* `IB` : 8비트 단위

  * `B0` → 비트 0~7
  * `B1` → 비트 8~15
  * `B2` → 비트 16~23

* `IW` : 16비트 단위

  * `W0` → 비트 0~15
  * `W1` → 비트 16~31

예시:

```text
%IX0.1.3 → 0번 베이스, 1번 슬롯, 3번 비트

%IB0.1.0 → 비트 0~7
%IB0.1.1 → 비트 8~15

%IW0.1.0 → 비트 0~15
```

관계:

```text
%IW0.1.0
= %IB0.1.0 + %IB0.1.1
= %IX0.1.0 ~ %IX0.1.15
```

※ 베이스와 슬롯은 물리적인 PLC 모듈 위치이고, 마지막 번호만 비트·바이트·워드 번호를 의미한다.

ASCII코드도 배움
