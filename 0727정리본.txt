# 0727 자동제어·PLC 수업 정리

* **교수님:** 장용선 교수님
* **학과:** 전자공학과
* **주요 내용:** 시퀀스 제어, 진법 변환, GLOFA 주소, ASCII 코드, 풀업·풀다운 회로

## 1. 자동제어와 시퀀스 제어

자동제어는 사람이 계속 조작하지 않아도 시스템이 정해진 목적에 따라 동작하도록 하는 제어 방식이다.

오늘 수업에서는 자동제어 중에서도 **정해진 조건과 순서에 따라 동작하는 시퀀스 제어**를 중심으로 학습했다.

```text
입력 감지 → 조건 판단 → 정해진 순서 실행 → 출력 동작
```

PLC는 스위치와 센서 등의 입력 신호를 읽고, 작성된 프로그램에 따라 판단한 뒤 모터·램프·실린더 등의 출력을 제어한다.

### 자판기 예시

```text
1. 돈 투입 감지
2. 투입 금액 확인
3. 상품 선택 버튼 확인
4. 금액과 재고 조건 확인
5. 상품 배출 모터 동작
6. 잔돈 반환
7. 초기 상태로 복귀
```

자판기는 각 단계가 조건에 따라 순서대로 진행되므로 대표적인 시퀀스 제어 시스템이다.

> 자동제어 전체가 시퀀스 제어인 것은 아니며, 시퀀스 제어는 자동제어의 한 종류이다.

## 2. 2진수와 16진수

PLC와 컴퓨터는 내부적으로 데이터를 0과 1로 처리한다.

긴 2진수를 읽기 쉽게 나타내기 위해 **4비트씩 묶어 16진수로 변환**한다.

```text
2진수 4비트 = 16진수 1자리
```

### 수업 예제

```text
2진수: 1011 0101 0010 1011
```

4비트씩 변환하면:

```text
1011 → B
0101 → 5
0010 → 2
1011 → B
```

따라서:

```text
1011 0101 0010 1011₂ = B52B₁₆
```

### 자주 사용하는 16진수 변환

```text
0000 = 0    0100 = 4    1000 = 8    1100 = C
0001 = 1    0101 = 5    1001 = 9    1101 = D
0010 = 2    0110 = 6    1010 = A    1110 = E
0011 = 3    0111 = 7    1011 = B    1111 = F
```

```text
1바이트 = 8비트  = 16진수 2자리
1워드   = 16비트 = 16진수 4자리
```

예:

```text
1111 1111₂ = FF₁₆
1111 1111 1111 1111₂ = FFFF₁₆
```

## 3. GLOFA 입력 주소

GLOFA의 직접 입력 주소는 다음과 같이 표현한다.

```text
%IX 베이스.슬롯.비트번호
%IB 베이스.슬롯.바이트번호
%IW 베이스.슬롯.워드번호
```

```text
%  : 직접변수
I  : Input, 입력 영역
X  : 1비트
B  : 1바이트, 8비트
W  : 1워드, 16비트
```

베이스는 PLC 모듈이 장착되는 랙의 번호이고, 슬롯은 해당 베이스에서 모듈이 장착된 물리적인 위치이다. GLOFA-GM 매뉴얼에서도 입력 주소를 베이스 번호, 슬롯 번호, 모듈 내부 접점 번호로 구분한다.

### 3.1 IX: 비트 단위

```text
%IX0.1.3
```

의미:

```text
0번 베이스
1번 슬롯
3번 비트 하나
```

주소는 0부터 시작하므로 `3번 비트`는 물리적으로 네 번째 입력점이다.

```text
%IX0.1.0 → 첫 번째 입력점
%IX0.1.1 → 두 번째 입력점
%IX0.1.2 → 세 번째 입력점
%IX0.1.3 → 네 번째 입력점
```

### 3.2 IB: 바이트 단위

`IB`는 입력을 8비트씩 묶어서 읽는다.

```text
%IB0.1.0 → 비트 0~7
%IB0.1.1 → 비트 8~15
%IB0.1.2 → 비트 16~23
%IB0.1.3 → 비트 24~31
```

마지막 숫자는 비트 번호가 아니라 **몇 번째 바이트인지**를 의미한다.

### 3.3 IW: 워드 단위

`IW`는 입력을 16비트씩 묶어서 읽는다.

```text
%IW0.1.0 → 비트 0~15
%IW0.1.1 → 비트 16~31
%IW0.1.2 → 비트 32~47
%IW0.1.3 → 비트 48~63
```

마지막 숫자는 **몇 번째 워드인지**를 의미한다.

### 3.4 IX·IB·IW 관계

같은 입력 데이터를 서로 다른 크기로 바라보는 것이다.

```text
%IW0.1.0
= %IB0.1.0 + %IB0.1.1
= %IX0.1.0 ~ %IX0.1.15
```

```text
X = 1비트씩 읽기
B = 8비트씩 읽기
W = 16비트씩 읽기
```

GLOFA의 입력 이미지 영역에는 입력 모듈에서 읽은 데이터가 저장되고, 프로그램은 `%IX`, `%IB`, `%IW`와 같은 직접변수로 해당 데이터를 접근한다.

> 슬롯은 1바이트짜리 저장 공간이 아니라 모듈이 장착되는 물리적 위치이다.
> 실제 사용할 수 있는 입력점 수는 장착된 입력 모듈의 점수에 따라 달라진다.

## 4. ASCII 코드

ASCII는 문자와 기호를 숫자로 표현하기 위한 문자 코드이다.

```text
문자 → 숫자 코드 → 2진수로 저장·전송
```

ASCII는 기본적으로 7비트 문자 코드이며, 실제 장치에서는 보통 8비트인 1바이트 단위로 처리한다.

### 주요 ASCII 코드

```text
문자 '0' → 10진수 48 → 16진수 30
문자 '1' → 10진수 49 → 16진수 31

문자 'A' → 10진수 65 → 16진수 41
문자 'B' → 10진수 66 → 16진수 42

문자 'a' → 10진수 97 → 16진수 61
문자 'b' → 10진수 98 → 16진수 62
```

### 주의점

```text
숫자 1      = 실제 수치 1
문자 '1'    = ASCII 코드 49, 16진수 31
```

두 값은 서로 다르다.

예를 들어 통신으로 문자열 `"123"`을 전송하면:

```text
'1' → 31H
'2' → 32H
'3' → 33H
```

가 전송된다.

PLC에서는 ASCII 코드가 다음과 같은 장치와 문자열 데이터를 주고받을 때 사용될 수 있다.

```text
PLC ↔ 컴퓨터
PLC ↔ HMI
PLC ↔ 바코드 리더
PLC ↔ 계측기
PLC ↔ 시리얼 통신 장치
```

### 주요 제어문자

```text
CR  → Carriage Return → 0DH
LF  → Line Feed       → 0AH
NUL → Null            → 00H
```

`CR`과 `LF`는 통신 데이터의 종료나 줄바꿈을 나타내는 용도로 자주 사용된다.

## 5. 풀업과 풀다운 회로

디지털 입력 단자가 스위치나 센서와 연결되지 않으면 전압 상태가 불확실한 **플로팅 상태**가 될 수 있다.

풀업 또는 풀다운 저항은 입력의 기본 상태를 확실하게 정해준다.

---

### 5.1 풀다운 회로

입력 단자를 저항을 통해 GND에 연결한다.

```text
VCC
 │
스위치
 │
 ├──── 입력
 │
저항
 │
GND
```

동작:

```text
스위치 OFF → 저항을 통해 GND 연결 → 입력 LOW, 0
스위치 ON  → VCC가 입력에 연결    → 입력 HIGH, 1
```

한 줄 정리:

```text
풀다운 = 평소 0, 스위치를 누르면 1
```

---

### 5.2 풀업 회로

입력 단자를 저항을 통해 VCC에 연결한다.

```text
VCC
 │
저항
 │
 ├──── 입력
 │
스위치
 │
GND
```

동작:

```text
스위치 OFF → 저항을 통해 VCC 연결 → 입력 HIGH, 1
스위치 ON  → 입력이 GND에 연결     → 입력 LOW, 0
```

한 줄 정리:

```text
풀업 = 평소 1, 스위치를 누르면 0
```

## 6. 풀업·풀다운 개념을 PLC 입력에 적용

마이크로컨트롤러에서는 풀업·풀다운 저항을 직접 연결하는 경우가 많지만, 산업용 PLC의 디지털 입력은 일반적으로 입력 회로와 COM 단자, 24V 전원, 스위치 또는 센서를 이용해 확실한 ON/OFF 상태를 만든다.

기본 개념은 동일하다.

```text
스위치가 열렸을 때 → 입력의 기본 상태 결정
스위치가 닫혔을 때 → 반대 상태로 변경
```

### 풀다운과 비슷한 PLC 입력

```text
스위치 OFF → 입력에 전압 없음 → PLC 입력 OFF
스위치 ON  → 입력에 24V 인가 → PLC 입력 ON
```

즉:

```text
평소 0
스위치를 누르면 1
```

### 풀업과 비슷한 PLC 입력

회로 구성이나 프로그램이 액티브 로우 방식이라면:

```text
평소 1
스위치를 누르면 0
```

으로 사용할 수 있다.

PLC에서는 NPN·PNP 센서와 입력 모듈의 소스·싱크 방식을 구분해야 한다. LS ELECTRIC 매뉴얼은 입력이 ON될 때 전류가 스위치에서 PLC 입력 쪽으로 흐르는 경우와 PLC 입력에서 스위치 쪽으로 흐르는 경우를 각각 싱크 입력과 소스 입력으로 구분한다.

```text
PNP 센서 출력
→ ON일 때 입력 단자에 +24V 공급

NPN 센서 출력
→ ON일 때 입력 단자를 0V 방향으로 연결
```

따라서 센서의 NPN·PNP 방식과 PLC 입력 모듈의 COM 배선을 서로 맞춰야 한다.

```text

시퀀스 제어
→ 조건과 순서에 따라 단계적으로 동작
```

```text
2진수 4비트 = 16진수 1자리

1011 0101 0010 1011
= B52B
```

```text
%IX = 입력을 1비트 단위로 읽음
%IB = 입력을 8비트 단위로 읽음
%IW = 입력을 16비트 단위로 읽음
```

```text
%IX 베이스.슬롯.비트번호
%IB 베이스.슬롯.바이트번호
%IW 베이스.슬롯.워드번호
```

```text
ASCII
→ 문자를 숫자 코드로 표현

'1'의 ASCII 값 = 49 = 31H
숫자 1과 문자 '1'은 서로 다름
```

```text
풀다운 = 평소 0, 스위치 ON 시 1
풀업   = 평소 1, 스위치 ON 시 0
```

```text
PLC 기본 흐름
입력 → 프로그램 연산 → 출력
```
